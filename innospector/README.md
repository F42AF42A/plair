# InnoSpector

Браузерная 3D-игра о защищённом инспекционном дроне.

Исходники игры находятся в этой папке. Дальнейшие изменения вносить здесь.
GitHub Pages публикует папку по адресу `/innospector/` вместе с основным сайтом.

## Локальный запуск

Из корня репозитория: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/innospector/`.
Нужен браузер с WebGL. Сборка и установка зависимостей не требуются.

## Файлы

- `index.html`, `style.css`: интерфейс и оформление.
- `game.js`: 3D-сцена, освещение, дрон, препятствия, звук, управление.
- `physics.mjs`: полёт и столкновения.
- `lidar-ray.mjs`: пересечения лучей сканирования с геометрией камней.
- `three.module.js`: локальная копия Three.js r170, лицензия MIT в `THREE-LICENSE.txt`.
- `drone-icon.png`: предоставленная владельцем проекта иконка для кнопок и favicon.

Удержание пробела или экрана поднимает дрон; отпускание снижает его.
Три столкновения завершают полёт. Очки равны пройденным метрам.
