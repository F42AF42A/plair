# SEO и контент

Обновлено 17 сентября 2026.

Сайт остаётся статическим HTML без сборки. Главная, страницы услуг и статьи доступны поисковикам без JavaScript. Новые страницы добавляйте в sitemap.xml и внутреннюю навигацию. Меняйте lastmod только при содержательных обновлениях.

У каждой страницы собственные title, description, canonical, H1 и JSON-LD. FAQ в JSON-LD должен точно соответствовать видимому FAQ. Для статей указана редакция PLAIR; имена и квалификацию экспертов добавлять только после подтверждения. Organization используется без неподтверждённого адреса, телефона и географии. Ценовые предложения и гарантии результата не заявлены.

Портфолио пока содержит демонстрационный концепт, не клиентский кейс. После добавления реальных проектов обновляйте content.js и статические описания на главной и в cases/index.html одновременно: контент должен совпадать с JavaScript и без него. Не публикуйте клиентские показатели и логотипы без оснований.

## Следующие шаги

- Завершить DNS и HTTPS, если домен ещё не обслуживается GitHub Pages.
- Подключить рабочий канал связи: сейчас форма отключена. После подтверждения публичного делового контакта и проверки доставки добавить /contacts/ и CTA на страницах услуг. Не публиковать личные адреса или токены ботов в репозитории.
- Подтвердить географию, опыт, сроки, диапазоны цен и данные компании; затем дополнить страницы и разметку.
- Подтвердить владение сайтом в Google Search Console и Яндекс Вебмастере, отправить https://plair.pro/sitemap.xml. Проверка файлов HTML сама по себе не означает индексацию.
- После публичного запуска проверить URL в Schema Markup Validator и Search Console. FAQPage описывает FAQ, но не обещает расширенный результат в поиске.
- Локальные профили создавать только при наличии фактических данных и соответствия правилам площадки.
