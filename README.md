# PLAIR

Портфолио игровых проектов для бизнеса. Чистые HTML, CSS и JavaScript, без сборки и зависимостей.

## Редактирование

- `content.js` — тексты кейсов, изображения, видео и настройки формы.
- `assets/` — файлы изображений и видео. Исходный PNG логотипа сохранён без изменений.
- `styles.css` — оформление и адаптивная вёрстка. Акцент: `#34C759`.
- `index.html` — структура страницы.
- `app.js` — переключение кадров, кейсов и форма.

Добавьте объект в `window.PLAIR_CASES`, чтобы появился следующий проект. Навигация отображается автоматически при наличии нескольких кейсов.

```js
{ type: "image", src: "assets/project.webp", alt: "Описание кадра" }
{ type: "video", src: "assets/project.mp4", poster: "assets/poster.webp", alt: "Описание видео" }
```

Сначала загрузите файлы в `assets`, затем укажите пути в `content.js`. Демо-кейс и его иллюстрации предназначены для первоначального наполнения; это не реальный клиентский проект.

## Публикация

В Settings → Pages выберите Deploy from a branch → main → / (root) → Save.
Файл `CNAME` содержит согласованный домен `plair.pro`. Настройте DNS домена после привязки в Pages.
Все последующие коммиты в `main` будут обновлять сайт.

Официальная инструкция: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

## Форма

Прямая отправка пока выключена. В `formEndpoint` нужно установить активированный HTTPS endpoint с непрозрачным идентификатором получателя. Для FormSubmit после подтверждения доставки установить `formActivated: true`.

Не помещайте секреты, ключи API или адреса личной почты в публичный репозиторий. Ошибка отправки не очищает введённые данные. Подтверждение показывается только при успешном ответе сервиса.

## Локальный просмотр

Из папки проекта запустите `python3 -m http.server 8000`, затем откройте `http://localhost:8000`. Локальный HTTP-сервер нужен в том числе для корректной загрузки маски логотипа.
